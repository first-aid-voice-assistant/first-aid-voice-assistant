# Proof of concept

The demo of the first-aid voice assistant. Its goal is to show the whole flow end to end as early as possible:

```
microphone → speech detection (VAD) → speech recognition (on the phone) → server → LLM → event log + voice prompt
```

| Part | Description | Status |
|---|---|---|
| [`server/`](server) | Test server (Python, FastAPI): receives transcripts, calls the LLM, returns the answer. | working (dev endpoint) |
| [`mobile/`](mobile) | Demo mobile app (Flutter): start screen and a test conversation – speech recognised on the phone, answer from the server, read aloud. | start screen and on-device speech recognition (three engines to compare) |

The PoC is a place for fast experiments. Code that proves itself here is later moved (or rewritten) into the target application in [`../apps`](../apps).

## Running the demo

1. Start the server: see [server/README.md](server/README.md) (`cd poc/server && docker compose up --build`).
2. Start the mobile app and point it at the server: see [mobile/README.md](mobile/README.md). From an Android emulator the server is at `http://10.0.2.2:8000`; from a physical phone use the computer's LAN address.

### Command for Claude Code

`/dev <part> [options]` (`.claude/commands/dev.md`) starts and stops the parts of the PoC. It calls `scripts/dev.ps1`, which can also be run by hand in PowerShell: `.\scripts\dev.ps1 <part> [options]`.

| Part | What it does |
|---|---|
| `llm` | Starts the Ollama container with GPU offload (always with the GPU override; `-Cpu` skips it) |
| `server` | Starts the LLM container (as `llm`; skipped for `-Model fake` or with `-NoLlm`) and then the server on the host; `-Model gemma\|bielik\|qwen\|fake` picks the config, `-EventLog` turns the event log on, `-Lan` lets a phone in the same Wi-Fi connect |
| `mobile` | Builds and runs the Flutter app; `-Device <id>`, `-Mode release\|profile\|debug`, `-Reverse` (`adb reverse` for a phone on USB) |
| `all` | `llm`, then the server and the app, each in its own window |
| `status` / `stop` | Shows what is running (container, GPU share, server) / stops the server and the LLM container |

Examples: `/dev llm`, `/dev server -Model qwen -EventLog`, `/dev mobile -Reverse`, `/dev stop`.

The mobile app uses the server API as documented at `/docs` of the running server (generated by FastAPI). The event-log entry format is described in [docs/project/architecture.md](../docs/project/architecture.md#event-log-entry).
